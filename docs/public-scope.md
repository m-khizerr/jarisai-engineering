# Public Case Study Scope

This repository is a technical case study, not the JarisAI production codebase.

## Included

- architecture concepts
- generalized domain models
- simplified pseudocode
- data-normalization strategies
- charge-engine design
- engineering challenges
- non-sensitive diagrams

## Intentionally excluded

- proprietary production source code
- licensed or commercial aviation datasets
- tariff databases
- credentials and infrastructure secrets
- customer information
- private APIs
- implementation-level proprietary calculation logic

Examples are simplified to explain the engineering approach without exposing protected product assets.
